Morinus 6.2 (the 2014 Windows version) on Python 3, with added tools for traditional astrology: planetary conditions, reception/generosity/repulsion, temperament, lunar returns of the solar year, return and transit steppers, duads on bi-wheels, unlimited lots with a Day/Night selector, and automatic time zones. See the [README](https://github.com/Cybergnostic/morinus_traditional_python3/tree/traditional#readme).

**Windows:** download `MorinusTraditional-…-setup.exe` and run it. It installs for your user account only (no administrator rights) and keeps your settings and charts when you update or uninstall. Windows may warn that the installer is from an unknown publisher, because it is not code-signed: choose *More info → Run anyway*. The `.zip` is the same program to unpack and run from any folder.

**Coming from the old Morinus:** copy your `.opt` files into the `Opts` folder, your charts into `Hors` and your `placedb.dat` into `Res`, inside the installation folder (`%LOCALAPPDATA%\Programs\Morinus Traditional`).

**Linux:** see the README.
